The [CNCF Kubernetes AI Conformance](https://github.com/cncf/k8s-ai-conformance) program defines extra capabilities, APIs, and configurations a Kubernetes distribution must provide — on top of standard CNCF Kubernetes Conformance — to run AI/ML workloads reliably.

NKP participates in this program. Use the table below to open the conformance evidence for each NKP release.
