The [CNCF Kubernetes AI Conformance](https://github.com/kubernetes-sigs/wg-device-management/blob/main/conformance/README.md) program defines extra capabilities, APIs, and configurations a Kubernetes distribution must provide — on top of standard CNCF Kubernetes Conformance — to run AI/ML workloads reliably.

NKP participates in this program. Use the table below to open the conformance evidence for each NKP release.

<div style={{ clear: 'both' }} />

## NKP versions

| NKP version | Kubernetes | Status | Details |
| --- | --- | --- | --- |
| **2.19** | v1.36 | Verified on 2.19.0-dev.34 | [NKP 2.19 AI Conformance](/docs/ai-conformance/2.19) |
| **2.18** | v1.35 | Certified | [NKP 2.18 AI Conformance](/docs/ai-conformance/2.18) |

2.19 is a development-build verification, not a CNCF submission. When a release is certified, its status in this list changes to Certified.
