The [CNCF Kubernetes AI Conformance](https://github.com/cncf/k8s-ai-conformance/blob/main/docs/AIConformance-1.37.yaml) defines additional capabilities, APIs, and configurations that a Kubernetes cluster MUST offer, on top of standard CNCF Kubernetes Conformance, to reliably and efficiently run AI/ML workloads.

This page shows how NKP 2.20 meets these requirements using Kubernetes v1.37.0 and the NVIDIA GPU Operator v26.3.3, deployed via Flux CD as platform HelmReleases. Hybrid verification (v1.37+) also collects upstream [kubernetes-sigs/ai-conformance](https://github.com/kubernetes-sigs/ai-conformance) suite artifacts under `v1.37/nkp/`.

<div style={{ clear: 'both' }} />

:::note
NKP holds **CNCF Certified Kubernetes** conformance, which AI Conformance builds on. That certification was submitted under NKP's former product name, **Konvoy**; see the [v1.36 Konvoy conformance submission](https://github.com/cncf/k8s-conformance/tree/master/v1.36/konvoy).
:::

## Support Dynamic Resource Allocation (DRA)

DRA v1 (`resource.k8s.io/v1`) is served. HelmRelease `nvidia-dra-driver` (chart `dra-driver-nvidia-gpu@0.4.1`) publishes DeviceClasses including `gpu.nvidia.com`, `mig.nvidia.com`, and `vfio.gpu.nvidia.com`.

```bash
kubectl get deviceclass
kubectl get resourceslice
```

ResourceSlice attribute `driverVersion` on `gpu.nvidia.com` is `580.126.20`, matching node label `nvidia.com/cuda.driver-version.full`.
